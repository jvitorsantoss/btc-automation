# BTC Automation

Automação em Python para acompanhar dados de Bitcoin em tempo real, desenvolvida durante meus estudos de programação e cibersegurança.

## Objetivo

O objetivo deste projeto é aprender, na prática, como se conectar a uma API de exchange via WebSocket e receber informações do mercado de Bitcoin em tempo real utilizando Python.

## Tecnologias

- Python
- websocket-client
- API WebSocket da Bitstamp

## O que estou aprendendo

- Protocolo WebSocket
- Conexões persistentes em tempo real
- Comunicação com APIs de exchanges
- Programação orientada a eventos (callbacks)
- Conexões seguras com SSL/TLS
- Tratamento de erros
- Bibliotecas Python

## Observação

Projeto desenvolvido exclusivamente para fins educacionais.
